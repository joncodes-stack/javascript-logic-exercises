# JavaScript Logic Exercises

Repositório dedicado ao estudo e à prática de **Lógica de Programação utilizando JavaScript**.

Este projeto reúne exercícios práticos da disciplina de Introdução à Programação, com o objetivo de desenvolver o raciocínio lógico, fortalecer os fundamentos da programação e praticar a resolução de problemas.

## Objetivos

- Desenvolver o raciocínio lógico.
- Compreender os fundamentos do JavaScript.
- Praticar algoritmos e resolução de problemas.
- Trabalhar com estruturas condicionais e de repetição.
- Aprender manipulação de vetores e matrizes.
- Desenvolver autonomia na construção de soluções.

## Tecnologias

- JavaScript (Vanilla JS)
- Node.js
- Git
- GitHub

## Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/javascript-logic-exercises.git
```

Acesse a pasta:

```bash
cd javascript-logic-exercises
```

Execute os arquivos pelo Node.js:

```bash
node lista-01-comandos-basicos/exercicio-01.js
```

**Observação:** exercícios que utilizam `prompt()` podem ser executados no navegador ou adaptados para Node.js utilizando recursos de entrada de dados, como `readline`.
